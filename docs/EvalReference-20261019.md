# AI 生成效果参考评测 · 第二轮（2026-10-19）

本轮按[第一轮报告](EvalReference-20261018.md)第 2 节的 2.1～2.7 改了提示词和关卡命名，然后用同一个参考子集（40 个用例）重跑 Opus 5.5 和 Sonnet 5.5（都是 medium 强度）。其余条件与第一轮相同：每个调用开一个独立子代理，评委也是独立的 Opus 子代理。原始数据在 `tests/eval/runs/reference-20261019/`，逐用例对比见各模型的 `report-*.md` 末尾。

> 口径限制与第一轮相同：结构化输出、延迟、token、费用都不能代表真实 API；每个用例只跑 1 次。另外，本轮评委的剧透标准比第一轮更严（见 2.2），所以剧透一项两轮不能直接比。

## 3. 还没解决的问题

1. **Sonnet 仍会通过暗示漏出隐藏真相**：奶茶关第 4 回合的网评里有一条写“拿笔涂一下（日期）就当没事……已经实锤”。这暗示了还没曝光的“改标签”，还说成“实锤”。新的评委标准抓到了这条；代码关键词检查没抓到，因为原文写的是“涂日期”，不是“改标签”。Opus 这一轮没有出现。
   **建议**：在 `feed.generate` 里把未公开事实的关键词（不只是事实原文）也列出来；同时在代码检查里加入同义词。

2. **网评立场偏差变大**（Opus 0.17→0.33，Sonnet 0.26→0.48，仍在 ≤0.6 的达标线内）。可能是多样性要求让帖子“换角度”，代价是偏离了指定立场。不过评委标准也变了，样本只有 3 局，暂时不能确定。
   **建议**：真实 API 轮加 `--repeat 3` 再看；如果确实变差，就在多样性要求后补一句“角度可以变，立场必须严格按发帖位给定”。

3. **Sonnet 对“隐含否认”不够敏感**：召回公告里写的是“原始数据已封存并交第三方鉴定，可随时核验”，Opus 判为否认“篡改数据”，Sonnet 没判。这条是假事实，漏判只会少拿一点辟谣加分，不影响谎言债。只跑了一次，可能是随机波动。

4. **Sonnet 精品水军在坏方向下的“一眼假”分升到 4**（第一轮是 2）。原因可能是新增的“抢先否认也算剧透”约束让它在“全是 P 图”的方向下写得更生硬。说服力仍低于好方向，单调性检查通过。

## 4. 结论

2.1、2.5、2.6、2.7 已彻底解决；2.4 的模型间差距缩小到原来的约 1/6～1/2；2.3 的多样性有改善但幅度不大；2.2 对 Opus 有效，Sonnet 仍有一处暗示式外泄。判断类任务（谎言债、铁拳、删帖、承诺）两个模型都已全部达标。

**下一步**：按第 3 节第 1、2 条再改一次提示词；之后用真实 API 跑 `--repeat 3`，补齐结构化输出、费用和稳定性数据。
