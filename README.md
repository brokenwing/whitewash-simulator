# 公关洗地模拟器

> 每一单都是一场舆论战。删帖、控评、水军、召唤铁拳……以及偶尔，说真话。

一款结合大语言模型的中式危机公关模拟游戏，纯 HTML/JS 实现，无需构建。你经营一家公关公司，每一关是一单委托：客户出了事，给你一笔预算和若干回合，你要在合同期内把舆论“洗”回来——同时提防甲方骗你、证据曝光打脸、水军被扒、对家召唤铁拳。

本作品为虚构讽刺作品，所有人物、品牌、机构均为虚构。

## 特性

- **关卡与引擎分离**：关卡是纯 JSON，引擎只认 schema；带可视化**关卡编辑器**（条件构建器、效果构建器、实时校验、一键试玩、导入导出、AI 一句话生成关卡）。
- **完整数值系统**：舆论好感、热度、公信力、暴露度、客户满意度；六类受众阵营各有敏感点；冲量与长期倾向分离——水军只能续命，整改才能治本。
- **真相与谎言债**：每条指控都有“客户口径”和隐藏真相。否认真事会记谎言债，证据曝光时当场打脸；辟谣真谣言则会在真相大白时得到印证。
- **18 种道具**：公文（AI 补全/评审）、水军（AI 按节奏方向写评论）、删帖与限流（一句话描述要删哪类帖，AI 筛选）、控评、撤热搜、买热搜、KOL、律师函、**召唤铁拳**（只砸真违规，举报说真话会回旋）、反向扒皮、舆情监测、内部调查、和解、招安、临时工、第三方背书、真诚整改，以及关卡自定义的 AI 道具。
- **对手盘**：对家品牌、维权群体、营销号……各有经典招式（抱团举报、告洋状、吃黑流量、召唤铁拳、翻旧账、造谣、截图存档、买水军反打），提前公示意图，部署舆情监测才能看清。
- **主任务与子任务**：阶段推进解锁道具层级、追加预算；可选子任务与客户临时加单带额外奖励。
- **四档难度**：实习生 / 正式工 / 金牌公关 / 地狱。
- **AI 可选**：支持 Claude（官方 SDK）与任何 OpenAI 兼容接口（DeepSeek、通义、Kimi、智谱、豆包、Gemini、Ollama、LM Studio……）。数值始终由引擎计算，AI 只写内容和有界打分；**不配置 AI 也能完整游玩**，所有 AI 功能都有离线规则兜底。
- **内置 4 关**：小龙虾店卫生风波（教程）、过期原料风波、顶流人设崩塌、智驾刹车门。

## 快速开始

推荐用自带的本地服务启动（只用 Python 标准库）：

```bash
python tools/serve.py
```

然后打开 <http://127.0.0.1:8765/Start.html>。关卡编辑器在 <http://127.0.0.1:8765/LevelEditor.html>。

也可以直接双击 `Start.html` 离线游玩（所有脚本都是普通 `<script>`，不需要服务器）。需要接入 AI、或者想让游戏和编辑器共享设置与自定义关卡时，建议用上面的本地服务。

## 接入 AI

在游戏标题页点「AI 设置」，选择服务商、填写模型和 API Key，点「测试连接」。Key 只保存在你的浏览器里。如果服务商不允许浏览器直接调用（跨域），用 `python tools/serve.py` 启动后勾选“通过本地代理转发请求”。详见 [docs/AI.md](docs/AI.md)。

## 制作关卡

打开 `LevelEditor.html`：以内置关卡为模板或从空白开始，按分区填写，右栏实时校验，点「▶ 试玩」直接在编辑器里玩。完成后可以：

- 「保存到浏览器」：游戏选关界面的“自定义关卡”里就能看到；
- 「导出 JSON」：发给别人，对方在标题页「导入关卡」；
- 「导出 JS」：放进 `levels/` 并写进 `levels/manifest.js`，成为内置关卡。

格式说明见 [docs/LevelFormat.md](docs/LevelFormat.md)。

## 目录

```text
Start.html            游戏入口
LevelEditor.html      关卡编辑器
css/                  样式（common / game / editor）
js/core/              命名空间、工具、事件、存储
js/data/              默认数据：道具库、技能库、难度、阵营、平台、文本池
js/engine/            引擎（无 DOM）：schema、条件/效果 DSL、舆论场、道具、演化、真相、任务、对手、评分
js/llm/               AI：设置与适配器、任务提示词、输出结构、离线规则
js/ui/                游戏界面
js/editor/            编辑器
levels/               内置关卡（manifest.js + 每关一个文件）
tools/serve.py        本地静态服务 + LLM 跨域转发
tests/run.js          单元测试与自动平衡模拟
docs/                 文档
```

## 测试

```bash
node tests/run.js
```

运行单元测试（含所有内置关卡的校验），并用机器人策略做一轮快速平衡模拟。更多参数：

```bash
node tests/run.js --balance 50 --diffs all
```

```bash
node tests/run.js --trace smart --level milktea --seed 3
```

前者跑完整平衡报告（每格 50 局、四档难度），后者打印单局逐回合的数值与日志。

AI 生成效果评测（需要自备 Key，或用 `--mock` 零成本自检）见 [docs/AI.md 第 8 节](docs/AI.md#8-生成效果评测开发用)：

```bash
node tests/eval/eval.js --mock
```
